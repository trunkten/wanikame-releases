# WaniKame – Releases

Public update channel for the **WaniKame** Android app (a native WaniKani client).
This repository holds only the built **APK files** as releases – **no source code**.
The source code lives in a separate, private repository.

## Notes

- All APKs are signed with the same key, so updates replace one another.
- No API token or similar is bundled; the app asks for your WaniKani token on first launch.
