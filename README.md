# WaniKame – Releases

Öffentlicher Update-Kanal für die **WaniKame** Android-App (nativer WaniKani-Client).
Hier liegen ausschließlich die fertigen **APK-Dateien** als Releases – **kein Quellcode**.
Der Quellcode bleibt in einem separaten, privaten Repository.

## Installation / Updates

Am bequemsten mit **[Obtainium](https://github.com/ImranR98/Obtainium)**:

1. Obtainium installieren.
2. Neue App hinzufügen und als Quelle die URL dieses Repositories eintragen:
   `https://github.com/trunkten/wanikame-releases`
3. Obtainium benachrichtigt bei neuen Versionen und installiert Updates auf Antippen.

Alternativ die neueste APK direkt unter **[Releases](../../releases/latest)** herunterladen
und installieren (dafür „Unbekannte Apps installieren" für den Browser/Dateimanager erlauben).

## Hinweise

- Alle APKs sind mit demselben Schlüssel signiert, sodass Updates sich gegenseitig ersetzen.
- Es wird kein API-Token o. Ä. mitgeliefert; die App fragt den WaniKani-Token beim ersten Start ab.
